# Deflate oracle

No fixtures: the inputs are generated by the tests in `src/deflate.rs`.
`zlib_oracle.py` gives MuPDF's deflate of an input at a zlib level, through
`mutool clean -z -e <effort>`, as the length and CRC-32 the tests pin:

```sh
mkdir /tmp/d && NUPDF_DUMP_DEFLATE_CASES=/tmp/d cargo test -p nupdf --lib deflate::tests::every_level
python3 zlib_oracle.py /tmp/d/runs.bin.9 /tmp/d/runs.bin.-1
```
